# macOS application and configuration inventory

Snapshot: 2026-08-04, macOS 26.5.2 (25F84), Apple Silicon.

This is the recovery boundary observed on the current Mac. Versions are an
audit snapshot; restore scripts intentionally install the latest compatible
version instead of pinning old GUI application builds.

## Automated recovery

Run from a clean Mac after installing Homebrew and signing into the Mac App
Store:

```bash
git clone git@github.com:mainliufeng/dotfiles.git ~/dotfiles
cd ~/dotfiles
./setup.sh
./link.sh
```

`macos/Brewfile` restores Homebrew formulae and casks, seven Mac App Store
applications, Go tools, `tauri-cli`, and global npm CLIs. The macOS setup then
installs these apps only when their existing application bundle is absent:

| --- | --- |
| `google-chrome` | Google Chrome 150.0.7871.187 |
| `microsoft-teams` | Microsoft Teams 26134.1610.4759.7759 |
| `openvpn-connect` | OpenVPN Connect 3.6.0 |
| `chatgpt-atlas` | ChatGPT Atlas 1.2026.189.1 |
| `doubao` | Doubao 2.12.7 |
| `typeless` | Typeless 1.6.0 |
| `wpsoffice-cn` | WPS Office 12.1.26015 |

`python/setup.sh` also restores the `notebooklm-py` pipx application.
`git/setup.sh` reconstructs the public user identity, Git LFS filters, and the
portable include pointing at `~/.rcrai.gitconfig`. `link.sh` restores the
tracked shell/editor/terminal configuration, htop layout, Hammerspoon config,
local helper apps, and LaunchAgents owned by this repository.

## State intentionally not committed

The following state exists locally but must be migrated separately or rebuilt:

- `~/.config/gh/hosts.yml`, `.cloudbase/auth.json`, `auth.json`, API keys, npm
  tokens, Telegram gateway env, SSH keys, certificates, and password/keychain
  data: secrets; authenticate again or use an encrypted private backup.
- Browser profiles, app cookies, chat histories, VPN profiles, and per-app
  account databases: mutable/private state, not dotfiles.
- Clash/Mihomo configuration and the rcrai Git include: owned by
  `~/dotfiles-private`; restore that repository separately.
- Codex tasks, memories, Scheduled definitions, plugins, and runtime SQLite:
  use the encrypted/explicit-target backup and restore suite in
  `~/dotfiles-private/codex`; never commit `~/.codex/auth.json`.
- LM Studio models, container images/volumes, local Kubernetes data, and other
  large caches: restore from a separate data backup or download/recreate them.
- Runtime-generated files such as `~/.profile` from uv, `~/.zprofile` additions,
  `.config/uv/uv-receipt.json`, htop history, shell history, logs, and updater
  LaunchAgents: regenerated by installers or intentionally excluded.

Large or private runtime roots observed during this audit are listed here so a
new-Mac migration does not silently mistake application installation for data
restoration. Sizes are approximate snapshots, not backup manifests.
