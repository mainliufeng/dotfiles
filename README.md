## Install

```sh
git clone git@github.com:Liu-Feng/dotfiles.git ~/dotfiles;
sh ~/dotfiles/install_dotfile.sh;
```

##### install all apps I'm using (Optional, not suitable for everyone)

```sh
sh ~/dotfiles/install_app.sh
```
