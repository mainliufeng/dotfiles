# Hyprland Skill Intro (Remotion)

该项目生成介绍 `hyprland` skill 的视频。

## 运行

```bash
cd remotion/hyprland-skill-intro
npm install
npm run start
```

## 渲染

```bash
npm run render HyprlandSkillIntro out/hyprland-skill-intro.mp4
```

产物默认位于 `remotion/hyprland-skill-intro/out/`。

内容来源：`/home/liufeng/.codex/skills/hyprland/SKILL.md`。
