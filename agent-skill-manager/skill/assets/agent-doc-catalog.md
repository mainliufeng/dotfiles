# Agent Doc Catalog

This file defines the runtime instruction documents that agent-skill-manager can render and sync in dialog.

## Targets

| target | output |
| --- | --- |
| codex | `~/.codex/AGENTS.md` |

## Fragment Sources

- Public fragments live under `assets/agent-doc-fragments/`
- Private fragments may live under `~/dotfiles-private/agent-skill-manager/assets/agent-doc-fragments/`

## Profiles

| target | fragments |
| --- | --- |
| codex | `base`, `gstack` |

## Project Overrides

| target | path | file | fragments |
| --- | --- | --- | --- |
| codex | `~/dotfiles` | `AGENTS.override.md` | `base`, `gstack` |

## Render Rules

- Prepend `<!-- Generated by agent-skill-manager -->`
- Join fragments in profile order with a blank line between fragments
- Resolve fragment names from the private overlay first when both public and private fragments exist
- The private overlay may add or replace profiles and append additional project overrides
- If an override path does not exist on the local machine, skip it and report the skip
