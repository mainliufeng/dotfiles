## gstack
```
优先使用 gstack 的 `browse` 及相关 QA skills 处理网页浏览、网页测试和截图，不要使用 `mcp__claude-in-chrome__*` 工具。

可用的 gstack skills：
- `plan-ceo-review`
- `plan-eng-review`
- `plan-design-review`
- `design-consultation`
- `review`
- `ship`
- `browse`
- `qa`
- `qa-only`
- `design-review`
- `setup-browser-cookies`
- `retro`
- `document-release`

如果 gstack skills 没有生效，运行：`cd ~/.claude/skills/gstack && ./setup`
```
